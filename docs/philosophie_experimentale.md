# Philosophie expérimentale du projet

## Pourquoi des runs immuables ?

Parce qu'un run est une observation : on doit pouvoir revenir exactement à :

- l'état d'entrée
- le flux d'événements
- l'état de sortie
- le lien causal (lineage)

Sans ça, on perd la capacité d'expliquer et de comparer.

## Pourquoi une promotion manuelle ?

Parce que “l'état courant” est une décision de laboratoire :

- on peut produire plusieurs runs
- comparer leurs artefacts
- choisir consciemment ce qui devient l'individu courant

Cela évite l'auto-corruption silencieuse et rend le projet gouvernable.

## Pourquoi un individu transportable ?

Pour rendre possible :

- l'isolement ontologique (l'individu est un paquet complet)
- la protection (chiffrement, signature)
- la portabilité (partage, archivage, réplication)
- la sélection (évolution, compétition, ensembles)
